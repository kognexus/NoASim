# NX-17: Impact policies (§2.1)

See [PLAN.md](../PLAN.md) for the behaviours (B*) and hypotheses (H*) referenced here.

## Acceptance criteria

- [x] Last-correct-state ring buffer
- [x] P1 retreat and hold with a synchronised return, SS2-style hold, fault and ACK gating
- [x] P2 SS1, brake, STO
- [x] P3 float
- [x] Configuration check against discovered brakes
- [x] H3b to H3d measured

## Tests

- `crates/nexus-node/src/supervisor.rs`: P1 returns to the pose 40 ms before the hit and
  holds until acknowledged; P2 stops, brakes, then cuts torque; P2 refused without a brake
- `sim/src/harness/impact.test.ts`: P1 tool back within 1 mm of the pre-impact pose,
  all six joints holding within one cycle, goals ignored until ACK (H3b); P1 presses less
  than stopping in place and lets go entirely (H3b); P2 with brakes stops, brakes, cuts
  torque and the brakes hold (H3c); P2 refused by every load-carrying joint of a brakeless
  arm (H3d)

## Log

- 2026-10-21: The supervisor (`supervisor.rs`) runs the same state machine on every joint,
  referenced to the detection's bus cycle, so the arm reacts as one without a central
  coordinator. P1: 20 ms compliant (the reference follows the joint; only damping and
  gravity remain), then a 0.5 s quintic back to the last correct pose (recorded every
  16 cycles while tracking within 0.02 rad, taken 40 ms before detection). The duration
  is the same on every joint, so all arrive together. A retreat faster than 1 rad/s is
  refused and the joint holds instead. Then a powered hold, a fault to the host, and
  goals ignored until the host sends ACK. P2: 0.2 s controlled stop, brake for 50 ms,
  then safe torque off on the hardwired line (the harness cuts every drive, whatever the
  bus does). P3: gravity compensation only. A comparison policy, stop in place, holds
  stiffly where the hit was detected.
- Brakes are a joint lock on the motor hinge, set to the angle at engagement. MuJoCo's
  default constraint softness let a braked arm sag by 28 mm; the lock is now stiff
  (2 ms, impedance ≈ 1): no motor drift, 0.7 mm at the tool from gear and link
  compliance.
- Results (seed 61): P1 tool back within 0.1 mm of the pre-impact pose, all joints
  holding in the same cycle. Mean contact force over the 0.5 s after detection 34 N
  against 54 N for stopping in place; at the end 0 N against 45 N sustained. P2 with
  brakes: brake at +0.23 s, torque off at +0.28 s, tool still afterwards. H3d: joints
  2, 3, 4 refuse P2 on a brakeless arm. Joints 1 and 5 turn about vertical axes, and
  joint 6's payload hangs along its axis in this pose, so they carry no gravity torque
  and keep P2.
