## Tests

- `crates/nexus-proto/tests/golden.rs` and `sim/src/bus/protocol.test.ts`: both codecs
  produce the bytes in `crates/nexus-proto/golden/frames.txt` and round-trip; unknown kinds
  and wrong lengths are rejected
- `crates/nexus-node/tests/actuator.rs`: power-on hold, silent until assigned, announce
  on assignment, READY with limits, torque limit enforced, follows goals, outbox overflow
- `crates/nexus-node/src/estimate.rs`: tracking observer recovers a ramp velocity
- `sim/src/node/wasmNode.test.ts`: per-joint memory isolation; config layout checked by
  the node echoing its EEPROM in its announcement; sensor layout checked by the node
  publishing its readings
- `sim/src/architecture.test.ts`: node-side code imports only nominal data

## Log

- 2026-10-21: `nexus-proto` defines fixed-layout little-endian frames (State, Goal,
  Limits, Announce, Assign) with an 8-byte header (kind, source, destination, cycle).
  The State frame is 80 bytes, so seven nodes publishing every cycle use 560 bytes of the
  ~3 kB a 100 Mbit/s bus carries per 250 µs cycle. The layout is pinned by golden bytes
  that both the Rust and the TypeScript codec must reproduce.
- `nexus-node` is an `Actuator` composed of `Estimator`, `Interpolator`, `Controller`
  and `SafetySupervisor` traits, with default stages (tracking-observer estimator, step
  interpolator, motor-side PD, torque limiter). Later tickets replace stages without
  touching the others. At power-on the node holds where it is, stays silent until
  assigned an address, announces its EEPROM data, and is READY once it has limits.
- The WASM I/O block now carries config, sensors, cycle, inbox and outbox. The module
  reports its own offsets (`nexus_layout`), so the harness hard-codes no offsets, and
  tests check config and sensor order end to end.
- Node addressing follows EtherCAT: the bus gives each node its line position (like an
  auto-increment address), and the host assigns IDs in NX-06.
- Full per-cycle pipeline (sensor models + node tick + drive physics) for two arms:
  3.5× real time in Node (`npm run bench:step`), down from 6.0× for plant and bare ticks.
  There is still enough headroom for the demo.
- Added `rustfmt.toml` (110 columns) to keep the Rust readable.
