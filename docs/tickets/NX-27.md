# NX-27: Headroom for learned damping

See [PLAN.md](../PLAN.md) for the behaviours (B*) and hypotheses (H*) referenced here.
Asked for by the owner: could reinforcement learning damp better than the fixed law?
Before training a policy, measure how much better any controller could do.

## Acceptance criteria

- [ ] An ideal reference controller that sees the plant's full state (every joint, every
  link's bending) with no bus delay, as an upper bound no real joint can reach
- [ ] The same per-joint torque limits and passivity budget as the joints have
- [ ] Measured against joint control only, joint-local and network damping on tap
  settling and task vibration, on both arms and both actuator grades
- [ ] A short finding: how much headroom is left for a learned damper, and where
  (which disturbances, which grades); a recommendation whether RL is worth it

## Tests

- The reference controller is deterministic per seed and its runs are part of the
  experiments, not the node
