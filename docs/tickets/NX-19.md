# NX-19: Experiment runner + proof report

See [PLAN.md](../PLAN.md) for the behaviours (B*) and hypotheses (H*) referenced here.

## Acceptance criteria

- [x] `npm run prove` is deterministic
- [x] Scenario matrix (mode × model × disturbance × posture × latency × seed), as each hypothesis needs it (see log)
- [x] H1 to H10 as tests
- [x] SVG plots

## Tests

- `experiments/src/prove/report.test.ts`: the report lists every finding with its verdict,
  missed targets included, and marks quick runs; the SVG writers produce self-contained,
  escaped files
- `npm run prove` itself: each hypothesis is measured and compared with its target in
  code (`experiments/src/prove/h*.ts`); `--quick` and `--only` for shorter runs

## Log

- 2026-10-21: **`npm run prove`** (`experiments/src/prove.ts`) builds the node, then runs one
  module per group of hypotheses and writes `docs/RESULTS.md` with SVG plots in
  `docs/results/`. Each module measures, compares with the plan's target and returns a
  verdict (met, partly met, not met, reported). The run is deterministic: fixed seeds
  throughout, and the learned models are the committed ones, re-scored with the new
  `nexus-train --evaluate`. Missing commissioning datasets are regenerated from their
  seeds. A full run takes about 16 min on a laptop.
- **What each hypothesis runs** (the "scenario matrix", by axis):
  - mode: H1 (joint control, joint-local, network), H5/H7 (network, alone, report to
    source);
  - model: H7 on hidden actuators, H10b (datasheet, RLS, learned);
  - disturbance: H1 taps, H3/H4 collisions and normal tasks, H5/H7 ripple;
  - posture: H1 (home and stretched out);
  - latency and loss: H6 (1–20 cycles, 0–20 %);
  - seeds: every module, none of them the tuner's.
- The experiment scripts became functions the proof calls (`measureReportToSource`,
  `measureRobustness`, `measureLearnedModels`); each keeps its command line.
- **Results** (`docs/RESULTS.md`):
  - met: H3a–H3d, H4, H5, H6, H10b, H10c, H10d;
  - partly met: H2 (path error better, jerk 1–3× not 5×), H7 (100/100, but joints alone
    are as good), H9 (3/6 joints within 1 %, payload +10 %), H10a (61 % on the sealed
    family, target 70 %);
  - not met: H1 (2.0–2.5× vs off; against joint-local damping 0.89–1.00×).
- **H1 under the proof's conditions is weaker than NX-11 measured.** The tuner found network
  damping 1.12–1.28× faster than joint-local damping, at its own seeds (11, 12) and at the
  home posture. With seeds 31–33 and a stretched-out posture added, it is even at best
  and slower on the KX-6L's stretched-out posture (0.237 against 0.211 s). The worst
  posture counts, so H1 is not met against joint-local damping. Reported as measured;
  nothing was re-tuned to the proof's seeds.
- Two full runs, before and after a text change in the H1 module, gave the same numbers
  to the last digit.
- ESLint now ignores Python virtual environments: `learning/.venv` ships JavaScript inside
  PyTorch, which made `npm run check` fail once `check:py` had created it.
