# NX-25: Network damping without extra vibration under a policy computer

See [PLAN.md](../PLAN.md) for the behaviours (B*) and hypotheses (H*) referenced here.
Found in NX-24: with the VLA computer (15 Hz goals), network damping made every joint's
housing vibrate 10–20 % more during a task than joint control alone. With the classic
controller it made no difference.

## Acceptance criteria

- [ ] The cause is measured, not guessed, and written down
- [ ] With the VLA computer, a network-damped arm's joints vibrate no more than with
  joint control only during pick and place and the figure of eight (KX-6L and KX-6,
  per joint, within 5 %)
- [ ] Tracking during tasks no worse than joint control only (NX-23 holds)
- [ ] Tap settling (H1) and the classic-controller numbers unchanged within 5 %
- [ ] `npm run prove` re-run; RESULTS.md and limitations updated

## Tests

- A harness test: under the VLA computer, network damping does not raise task vibration
- Rust and TypeScript suites passing
