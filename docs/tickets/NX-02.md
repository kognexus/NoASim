# NX-02: ArmSpec → MJCF plant

See [PLAN.md](../PLAN.md) for the behaviours (B*) and hypotheses (H*) referenced here.

## Acceptance criteria

- [x] KX-6 default with QDD joints and optional brakes
- [x] N-joint generator
- [x] Modal impulse test gives the first mode at 8 to 15 Hz and 1 to 3% damping
- [x] Unit tests

## Tests

- `sim/src/plant/mjcf.test.ts`: spec validation, generated sizes (KX-6, locked motors, 3-joint arm),
  bending axes, IMU on the housing
- `sim/src/plant/plant.test.ts`: initial pose, motor torque and gear twist, IMU placement,
  gravity sag with locked motors, **structural modes in band** (acceptance)
- `sim/src/analysis/modal.test.ts`: frequency and damping recovered from a synthetic decay

## Log

- 2026-10-21: `ArmSpec` → MJCF generator, `Plant` wrapper, impulse modal test. Each joint
  is a motor hinge (armature = rotor inertia × ratio²) in series with a gear spring hinge.
  Each flexible link has two bending hinges at mid-length. The IMU sits on the actuator
  housing, so joint *i*'s IMU moves with link *i−1*. That is where the board is on real
  hardware, and it means link flex shows up in the *next* joint's IMU, which is what
  neighbour data is for.
- Modal test definition: motors locked (no controller), gravity off, 50 N × 2 ms tap at
  the tool, stretched-out pose (the worst case). Tuning: gear stiffness 6e4 N·m/rad
  (large joints), link bending stiffness 1.2e5 / 6e4 N·m/rad, damping raised until the
  first modes reached the target. Result: **vertical 9.66 Hz, ζ 1.57 %; lateral 12.47 Hz,
  ζ 2.72 %** (axial 14.8 Hz, ζ 1.1 %). With the motors under a position loop, the modes
  will sit lower. That is measured in NX-07.
- Found and fixed: MuJoCo named-access addresses are scalars in this binding version. The
  NX-01 benchmark had read them as arrays, so its nodes saw zero sensors. The benchmark
  now runs on the KX-6 plant, and ADR-0002 has an update section with the new numbers
  (2 arms, 12 nodes: 6.0× real time).
