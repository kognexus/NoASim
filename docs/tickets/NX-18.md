# NX-18: Limits, announcements, thermal headroom (B6, B7)

See [PLAN.md](../PLAN.md) for the behaviours (B*) and hypotheses (H*) referenced here.

## Acceptance criteria

- [x] Host limits enforced every cycle
- [x] Every local action announced in the same cycle
- [x] Derating announced in advance

## Tests

- `crates/nexus-node/src/safety.rs`: torque clamp with nothing reported in range; warning
  before derating, derating reported once; position wall and speed brake reported
- `sim/src/harness/limits.test.ts`: a fast-heating shoulder warns at least 0.1 s before it
  derates, and the derating reaches the host as a `Limit` fault; a 0.3 rad/s speed limit
  holds during a fast reach (averaged speed below 1.5× the limit; measured 1.34×) and is
  reported

## Log

- 2026-10-21: `LimitSupervisor` replaces the torque clamp. Every cycle, with its own data,
  the joint enforces the host's torque limit, a virtual wall beyond its position range, a
  speed brake beyond its speed limit, and thermal derating. It publishes thermal headroom
  (share of the band from ambient to the limit). Below 20 % headroom it sets
  THERMAL_WARNING; below 10 % it derates linearly to half the torque limit and sets
  DERATING. Each limit is reported to the host as a `Limit` fault the cycle it starts
  acting (at most once per 0.25 s if it flickers). All other local actions (network
  damping, stopping, holding, torque off) are status bits in the same cycle's state
  frame. So the host is never surprised by its joints.
- The node also rate-limits its reference to the speed limit, so a joint follows a slower
  reference instead of falling behind a fast one. A stiff speed brake alone made the light
  wrist joint oscillate at the bus rate; the brake is now small and the reference does
  the work. Side effect: the rate limit smooths the central baseline's setpoint stream,
  and H2 is re-measured in NX-10.
- Measured: the averaged joint speed overshoots a 0.3 rad/s limit by about a third
  during a fast reach (servo dynamics; the reference itself never exceeds it).
