# NX-04: Hidden actuator families

See [PLAN.md](../PLAN.md) for the behaviours (B*) and hypotheses (H*) referenced here.

## Acceptance criteria

- [x] Structurally different actuator models (friction, ripple orders, nonlinear and hysteretic stiffness, backlash, thermal Kt drift), randomly drawn per joint with a seed
- [x] One family sealed for the out-of-family test
- [x] A test checks that nodes can't see the draw

## Tests

- `sim/src/actuators/actuators.test.ts`: friction opposes motion in every open family,
  cogging vs ripple, torque-constant drift, Dahl hysteresis dissipates, backlash play,
  reproducible draws with mixed families, sealed family never drawn unless asked,
  every family (sealed included) drives the plant without diverging
- `sim/src/actuators/sealed.test.ts`: sealed file hash unchanged
- `sim/src/architecture.test.ts`: node-side code cannot import plant, actuators or
  analysis; node crates depend only on each other

## Log

- 2026-10-21: Hidden actuators are compositions of `ActuatorEffect`s (friction, drive
  torque, gear torque, torque-constant scale) behind the `ActuatorPhysics` interface that
  `IdealDrive` also implements. With hidden actuators the MJCF is built with
  `externalFriction`, so friction comes only from the actuator physics; gear deviations
  from the linear spring go on the gear hinge as generalised forces.
- Open families (parameters drawn around the datasheet values per joint):
  `textbook`, `stribeck-position`, `ripple-thermal`, `hysteretic-stiffening`, `backlash`.
- **Sealed family** `sealed-lugre-eccentric` (LuGre friction with direction asymmetry,
  eccentric gear stiffness, load-squared ripple) in `sim/src/actuators/sealed.ts`.
  SHA-256 at sealing: `23cc7c06ce1fa16e66a11589d2d320e17d658134f46098367a760349a12c9cd3`. Its only use so far is the
  stability smoke test (it must run without diverging); it has not been used to fit,
  train or tune anything.
- Coulomb friction uses a smooth sign (tanh, 0.01 rad/s) so explicit friction stays
  stable at 4 kHz; stiction therefore shows as slow creep rather than a hard stop.
